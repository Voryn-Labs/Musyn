**Musyn 0.3.1** by **Voryn Labs**.

- YouTube Music works without keys; JioSaavn is optional and uses your own media URL key stored in iOS Keychain. No JioSaavn key is bundled. Add or remove it in Settings → JioSaavn.
- A new walkthrough step, integrated Settings, Privacy, Terms and Support pages.
- Refined download/source sheets, queue accents and mini-player rendering. Same-track artwork refreshes remain visible while position-only updates avoid unnecessary redraws.
- Redacted diagnostic previews with explicit dpaste upload and a GitHub issue draft. No automatic log uploads.
- Opt-in native iOS 26 glass and real video artwork. Attach a silent square or portrait clip from a song's menu. Tracks without one keep still covers; iOS controls lock-screen presentation. No automatic Spotify/Apple artwork lookup is included.

**Install:** iOS 15+, unsigned `Musyn.ipa`; `com.vorynlabs.musyn`, **0.3.1 (13)**. Sign with your own identity or use a compatible LiveContainer host. Native glass/animated Now Playing require iOS 26.

Provider terms, permissions and content rights apply. Bringing a key does not grant service access rights. Earlier releases and CI build artifacts have been withdrawn, and published Git history has been sanitized. Existing copies and cached objects cannot be recalled.
