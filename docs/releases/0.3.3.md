**Musyn 0.3.3 (15)** by **Voryn Labs**.

- Animated album covers are now found automatically on iOS 26. No manual import, Apple/Spotify account or extra key is required. Match the selected track through Apple’s public catalog and album page; cache an available real clip for the player and supported lock screen.
- Conservative title/artist/duration matching, stale-request cancellation, native file validation and still-cover fallback. Audio does not wait for artwork.
- Bounded artwork cache (80 MB / 20 clips), rate/backoff handling, Offline/Reduce Motion/Low Power checks and a Clear Artwork Cache action.
- Automatic artwork defaults on for supported systems with no saved preference; existing explicit opt-outs remain off. Appearance and Privacy explain provider requests and the switch. Manual import actions are removed.

Not every album has motion artwork. Spotify Canvas lookup is not included. YouTube remains keyless; optional JioSaavn still uses the user’s Keychain entry with no bundled key. iOS 15+, unsigned Musyn.ipa, bundle com.vorynlabs.musyn.
