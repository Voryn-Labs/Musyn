The first **Musyn** preview, by **Voryn Labs**.

- YouTube Music and JioSaavn AAC sources, explicit source/quality selection.
- Home, Explore, Library and Search; real chart collections.
- Queue, lyrics, gestures and a full player.
- Offline track/playlist downloads with progress, cancellation and retry.
- New folded music icon, native launch screen and startup recovery.

**Install:** iOS 15 or newer. `Musyn.ipa` is unsigned: sign it with a compatible installer or import it into a compatible LiveContainer version. This is a fresh application, `com.vorynlabs.musyn`, version 0.1.0 (1).

This preview passes automated tests and an iOS release build. Physical iPhone playback, background transitions and installer-specific behavior still need device acceptance. Download counts represent file requests, not verified installations. No lossless or addon support is claimed.
