**Musyn 0.1.1** update by **Voryn Labs**.

- **Lock-screen continuous playback**: Fixed rapid skipping queue starvation using a 4-item metadata buffer and 1-track stream pre-warm model; lock-screen and Control Center controls now remain continuously available without manual unlock.
- **Auto-queue recommendation reliability**: Prevented unhandled invalid ID exceptions on non-YouTube tracks by resolving recommendations via track metadata queries.
- **Offline downloads**: Repaired JioSaavn track downloads and token validation so all catalog tracks download without ID mismatch errors.
- **Cupertino glass ancestral screens**: Replaced legacy dialogs with Apple Music-inspired frosted glass sheets (Source Picker, Download Picker, left-aligned synced lyrics with album art aura background).
- **Settings redesign**: Added iOS Settings-style colored icon tiles, Apple Red accents, and improved layout responsiveness for large dynamic text.
