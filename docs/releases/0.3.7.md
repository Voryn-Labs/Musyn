# Musyn 0.3.7 — focused playback, Sing Along upcoming

- Mark Sing Along as coming soon in the player and lyrics screen. The slow experimental preparation path is disabled; opening its preview downloads no model/audio, runs no separation and does not change playback. Normal synced lyrics, lyric seeking and lock-screen lyrics remain available.
- Add native CarPlay audio browsing for Queue, Downloads, Favorites and Recent, plus Apple's Now Playing screen. The phone and car use one shared player. CarPlay attaches playback/library listeners only while connected; no car catalogs, timers or extra requests run during normal phone use. Reject disconnected/stale selections and handle late connection handshakes safely.
- Retain on-demand vocal processing work for future development: cache lookup before repeat downloads, parallel verified model setup and a bounded rolling PCM reader. This is groundwork, not a released near-instant vocal-reduction engine.

CarPlay requires Apple's approved audio entitlement in the profile used to sign the app. Ordinary sideloading does not grant that capability. Native compilation is verified; real head-unit/cold-launch and iPhone route/background acceptance remain outstanding.

Validation: 281 Flutter tests, analyzer, public-source credential/upload guards and branding checks. Fresh Flutter renders visually reviewed for the upcoming-feature dialog and player menu. Native rolling-reader fixtures verify overlap ordering, complete tails, cancellation and stereo/mono 48 kHz conversion. Existing DSP, lyrics and synthetic separation/mix fixtures are also run before release.
