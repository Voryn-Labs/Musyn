**Musyn 0.1.5** by **Voryn Labs**.

- Compact player controls and more space for lyrics, with a continuous artwork background.
- Native tab layout reserves room for the mini-player, protecting Library and Explore content. Search has a compact browse introduction and correct dark-screen status-bar styling.
- Smaller source and download sheets, clearer quality limits and actual transfer bitrate/provider reporting. AAC is no longer labeled lossless.
- Official YouTube chart collections grouped into songs, music videos, trending and languages, with India/Global/US/UK selection. Missing regional song charts no longer trigger a false Home refresh error. Chart Play starts the actual ordered playlist.
- Seek-bar taps use the touched position; cancelled drags do not seek. Late autoplay recommendations cannot refill a cleared queue. Downloads reject incomplete or overlong known-size payloads and keep the previous saved copy.
- Native iOS Favorite command shares the app's favorites store. iOS chooses where to expose this action; an always-visible lock-screen heart is not guaranteed.

**Install:** iOS 15+. `Musyn.ipa` is unsigned; sign it with a compatible installer or import it into a compatible LiveContainer version. Bundle `com.vorynlabs.musyn`, version 0.1.5 (6).

Automated rendering and tests cover layout and command behavior. Physical iPhone lock-screen Favorite presentation, background playback and provider transitions still require device acceptance. The shared Voryn Labs installer catalog is refreshed manually by the maintainer.
