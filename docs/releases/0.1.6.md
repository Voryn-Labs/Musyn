**Musyn 0.1.6** by **Voryn Labs**.

- Fix the prepared-stream map error that sent valid JioSaavn playback through an unnecessary YouTube fallback.
- Rapid song selections interrupt abandoned native loads instead of waiting behind them. Source replacement keeps playback intent active, starts URL preparation immediately, and uses native HTTP headers with a smaller forward buffer on iOS.
- Save a default download source and quality in Settings. Downloads start with one tap, automatically try the other enabled provider after failure, and show a brief fallback notice. Per-track overrides remain in Track Options. Retry progress clears the previous provider's byte count and bitrate.
- Upgrade low-resolution covers and prepare a shared square local cover for the app and lock screen, removing YouTube thumbnail letterboxing. A late cover cannot replace a newly selected song's artwork.
- Center synced and plain lyrics, use a pink active line, and keep line sizes stable while following playback. Landscape places artwork and transport beside lyrics, following the supplied reference.
- Refine the mini-player and full player. The iOS output button opens the system AirPlay/Bluetooth picker; playback-source selection and download controls are in Track Options.

**Install:** iOS 15+. `Musyn.ipa` is unsigned; sign it with a compatible installer or import it into a compatible LiveContainer version. Bundle `com.vorynlabs.musyn`, version 0.1.6 (7).

Automated tests cover rapid-selection races, prepared metadata, download fallback/cancellation, artwork cropping and late artwork, and player layouts. Physical iPhone transition latency, background behavior and AirPlay presentation still require device verification. Uncached network streams still need time to resolve and buffer. The shared Voryn Labs installer catalog remains manually refreshed by the maintainer.
