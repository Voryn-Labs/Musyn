**Musyn 0.1.8** by **Voryn Labs**.

- Repair YouTube Liked Music loading through its authenticated Music collection instead of a public playlist URL. Start library sync immediately after connecting.
- Preserve local favorites when YouTube fails. Queue local like/unlike edits durably, retry failed writes and protect newer taps from stale responses. Show actual sync state in account settings.
- Improve artwork resolution with HD video covers, fallback images and larger album covers. Preserve existing high-resolution sources and refresh the prepared-cover cache.
- Keep known lock-screen duration through temporary native zero-duration events. Failed provider selection preserves the working player item when no native replacement occurred.
- Add native animated artwork on iOS 26+: gentle, silent artwork loops generated on demand and cached locally. Older systems and system accessibility/power settings retain still artwork.
- Reorganize Settings into focused native pages with large-text layouts. Match native and Flutter splash branding, keep the requested minimum launch duration and expose progress only for slow startup.

**Install:** iOS 15+. `Musyn.ipa` is unsigned. Bundle `com.vorynlabs.musyn`, version 0.1.8 (9). Use your own signing identity with a compatible installer, or import into a compatible LiveContainer version.

The existing optional YouTube connection is retained. Spotify linking has been researched but is not included; it requires a registered OAuth client and appropriate Spotify API access. Full findings and remaining device checks are in `docs/DEVICE_LOG_AUDIT_0.1.8.md`.
