**Musyn 0.1.7** by **Voryn Labs**.

- Fix YouTube charts getting stuck loading. Public charts no longer depend on account cookies, refresh YouTube's current web client version, and retain a recent country-specific chart list for temporary network failures. Home shows an explicit retry state when charts cannot load.
- Keep lock-screen artwork square from its first publication, including previously downloaded covers. Playback metadata updates immediately while the square cover prepares; late artwork cannot replace the next track.
- Animate artwork gently and continuously while music plays, including landscape. Pause holds the artwork still; Reduce Motion disables the animation.
- Put Download directly on the player. Your saved download source and quality apply immediately, with automatic fallback and a brief notice when another enabled provider is needed. Per-track overrides remain in the menu.
- Replace the options menu with native iOS actions. Simplify Downloads to saved music and active transfers, and reorganize Settings into native grouped rows.
- Integrate the mini-player into the navigation surface and remove its progress line. Apply the Musyn coral brand accent, add a skippable three-page walkthrough with replay in Settings, and keep the branded splash visible for at least 1.8 seconds while startup runs in parallel.

**Install:** iOS 15+. `Musyn.ipa` is unsigned; sign it with a compatible installer or import it into a compatible LiveContainer version. Bundle `com.vorynlabs.musyn`, version 0.1.7 (8).

Validation: 182 Flutter tests passed locally, static analysis is clean, and branding/plist checks pass. UI renders cover light/dark themes, small screens, landscape and large text. Native compilation is verified by the release workflow; physical iPhone lock-screen presentation and animation smoothness still need device verification.

YouTube connection remains optional and uses Musyn's own session. This release does not silently import an iPhone or another app's Google account. A native Google sign-in flow requires a registered iOS OAuth client and user consent. The shared Voryn Labs installer source remains manually refreshed.
