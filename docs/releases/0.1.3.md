**Musyn 0.1.3** update by **Voryn Labs**.

- **BitChord Design System Unification**: Standardized all modal bottom sheets, menus, and controls to BitChord's frosted acrylic card architecture (`PlayerDrawer`).
- **Native iOS Gesture Navigation**: Restored iOS edge-swipe back navigation across the entire app routing tree (Settings, Playlists, Albums, Artists, Downloads, Charts, Folders) via `CupertinoPage`.
- **Full-Stage Synced Lyrics**: Transformed the lyrics view into an expansive, Apple Music-style full-height stage over blurred artwork, with frosted header navigation and a streamlined compact transport dock.
- **Player Gesture Controls**: Added horizontal fling gestures on album artwork with spring physics and haptics to skip tracks, horizontal drag on lyrics/queue to return to artwork, and tap-to-dismiss on the grab handle.
- **Unified Bottom Drawers**: Replaced disparate ancestral sheets for Source Selection, Download Options, Settings Quality/Provider, and Download Sorting with high-fidelity frosted cards and 50% dark backdrop scrims.

**Install:** iOS 15 or newer. `Musyn.ipa` is unsigned: sign it with a compatible installer or import it into a compatible LiveContainer version. Application `com.vorynlabs.musyn`, version 0.1.3 (4).
