# Musyn 0.1.7 verification

The reported chart failure had a concrete asynchronous deadlock: `whenComplete(() => _chartRequests.remove(region))` returned the very Future being completed. Successful responses therefore never reached Home. Cleanup now uses a void block, and a regression test verifies two concurrent callers both complete after a single request. Charts use public WEB_REMIX requests with a current client version read anonymously from YouTube Music, avoiding expired account cookies. Country-specific official chart lists are cached for three days as an offline fallback. Home has visible loading and retry states. No search results are substituted for charts.

Now Playing previously received the original wide thumbnail before its square replacement arrived. The native metadata now contains no artwork until a square local cover is ready. In-app views retain the original image in metadata extras so they can render during preparation. Local downloaded covers also pass through square preparation. The stale-cover test verifies a delayed result for a previous track cannot replace the current cover. Existing pixel tests cover thumbnail letterbox removal and square output. There is no physical iPhone screenshot verification on this host.

Artwork has a continuous fourteen-second float/tilt animation while playing, in portrait and landscape. It holds its pose on pause and becomes stationary under Reduce Motion. A dedicated test advances time and verifies those three behaviors. Headless UI renders use Reduce Motion so they can settle; they do not measure device frame rate.

Player Download is a direct action outside the native track menu. It uses the existing persistent defaults, provider fallback, cancellation and atomic-save pipeline. The native menu preserves queue, favorites, playlists, source override, download override, sleep timer, details and removal actions. Downloads hides duplicate completed transfer cards by default, retaining recent transfers and cleanup in its options menu. Settings preserves source/quality, theme, offline/autoplay, account, repair, cache/history and diagnostic controls using native grouped rows. Download preference changes still do not invalidate playback caches.

The mini-player shares the page/navigation surface without a capsule border or progress line. Coral action colors follow the existing Musyn logo; playback and lyric colors retain their functional meaning. The longer splash runs initialization in parallel with a 1.8-second minimum and immediately exposes errors. The walkthrough is skippable, scrollable at large text sizes, persisted once, and replayable from Settings. Completing it replaces the first-run subtree so Back cannot reopen it.

Google account discovery is intentionally not claimed: iOS apps cannot silently reuse another app's private account session. The existing optional YouTube connection remains. Native Google sign-in requires a Google Cloud iOS OAuth client for `com.vorynlabs.musyn`, configuration and explicit consent; no such client is configured in this repository.

Local checks: 182 Flutter tests passed; `flutter analyze` reports no issues; `verify_branding.py` and both iOS plist checks pass. Headless renders in `docs/ui-review/` cover light/dark, small screens, large text, landscape, menus, downloads, settings and all walkthrough steps. This host has no full Xcode installation or iOS simulator. Native release build and artifact checks are recorded after publication. Physical background playback, lock-screen presentation, AirPlay and animation frame pacing remain device acceptance checks.
