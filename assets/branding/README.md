# Musyn brand assets

Musyn uses a coral folded M/music monogram on warm charcoal, derived from the Voryn Labs folded-mark family. The Voryn Labs studio mark retains its original gold treatment.

The icon is opaque, square, and supplied at 1024 px. iOS applies its own external icon mask. Native-size derivatives are generated with `sips`; no fonts or external marks are embedded.
